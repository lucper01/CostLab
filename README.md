# CostLab Calculator

CostLab Calculator is a local-first, multi-study research budgeting application for planning, comparing and monitoring experimental research costs.

The application supports multiple studies simultaneously, direct and full-cost budgeting, participant-related costs, consumables, personnel, equipment, services, travel, funding sources, real expenses, procurement needs, scenario modelling, Monte Carlo simulations, CSV/JSON exports, local backups, and installable PWA use.

All study data are stored locally in the user's browser/application environment. GitHub hosts the application code only.

## Use

Open the GitHub Pages site in a modern browser. The application can also be installed as a PWA. A Windows installer can be built and published through GitHub Actions and downloaded from the application's Windows download button.
